Install, update, and customize the open-source exporter • Last updated September 29, 2026

Quick start (userscript)

  1. Install a userscript manager: Tampermonkey or Violentmonkey.
  2. Install the exporter script from GreasyFork:
    • Markdown exporter
    • PDF exporter
  3. Open ChatGPT, refresh once, and choose Export to Markdown or Export to PDF from the conversation menu. If sharing is unavailable, use the floating Export button.

Updates arrive automatically; your manager will prompt you before applying new versions.

Console method

For restricted environments or quick one-off exports, run the exporter from the browser console without installing anything.

Markdown console exporter

Copy the complete Markdown exporter, open Developer Tools (F12), paste it into the Console, and press Enter. Text-only conversations download as .md. Conversations with available image bytes download as .zip.

PDF console exporter

Run the complete PDF exporter in the same way. Open its downloaded HTML file, then use Print / Save as PDF.

Gemini support

Open a conversation at gemini.google.com, then copy the complete Gemini Markdown exporter into its browser Console.

  • The filename uses your conversation title and date.
  • Text-only chats download as .md; available image files are bundled in a ZIP.
  • Experimental Gemini layouts may require selector tweaks — open an issue if you hit one.

Troubleshooting

Export button missing

Ensure the script is enabled and refresh the tab. In Tampermonkey, the icon should be green on ChatGPT/Gemini domains.

Partial exports

Expand all messages before exporting. Collapsed responses are skipped because the DOM isn’t loaded.

Images & attachments

Markdown with image bytes downloads as a ZIP containing the document and an images/ folder. Extract it and keep the folder beside the document. Image files can be opened or copied individually. Unavailable images remain links or readable placeholders.

Styling tweaks

Fork the repo, edit the shared engine in src/extraction-engine.js, and run npm run build to regenerate the exporters. Contributions welcome.

Privacy & security

  • Runs in your browser, with optional authenticated reads from ChatGPT and image downloads from the provider’s CDN; no conversation content is sent to this project.
  • Open-source under MIT — audit every line on GitHub.
  • No analytics, telemetry, or third-party dependencies beyond the userscript manager/CDN.
