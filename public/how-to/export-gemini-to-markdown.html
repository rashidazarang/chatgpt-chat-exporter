How to Export Gemini Conversations to Markdown

Updated September 29, 2026 • 3 minute read • By Rashid Azarang

The Gemini console exporter saves responses as clean Markdown with headings, lists, code, math and tables. Available image bytes are saved as files in a ZIP with the document.

This guide covers console export and common troubleshooting tips.

Install and export

1

Open your Gemini conversation

Go to Gemini and open the conversation you want to save.

2

Copy the exporter

Copy the complete Gemini Markdown exporter from GitHub.

3

Run the exporter

On your Gemini tab, open Developer Tools (F12), paste the exporter into the Console, and press Enter.

4

Export your Markdown

The file downloads automatically. Text-only chats save as .md. Chats with available image bytes save as a ZIP containing the document and an images/ folder. Extract the ZIP and keep the folder beside the document.

Console-only workflow? Head to the documentation for the Gemini snippet and manual instructions.

Compatibility notes

  • Supports Gemini’s default and “Pro” modes. Labs/experimental UIs may change selectors — report issues on GitHub.
  • Images export as references (similar to ChatGPT). Download originals from the Gemini interface if needed.
  • Markdown naming follows the Gemini conversation title with -gemini.md suffix.
